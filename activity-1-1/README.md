# A1.1 Aprendizaje Estadístico Automático – Análisis de Obesidad

## Descripción
En esta actividad se realiza un análisis exploratorio de datos (EDA) sobre niveles de obesidad en población latinoamericana, utilizando variables demográficas y de hábitos de vida.

El reporte documenta el proceso de análisis mediante tablas, gráficas y estadísticas descriptivas, permitiendo comprender los resultados sin necesidad de revisar el código.

## Contexto
La obesidad es un problema creciente en países como Colombia, México y Perú. El conjunto de datos fue recopilado por investigadores de la Universidad de la Costa (Colombia) con el objetivo de estudiar los distintos niveles de obesidad y sus posibles factores asociados.

## Objetivo
Analizar la distribución del nivel de obesidad y evaluar si existen diferencias relevantes entre hombres y mujeres.

## Metodología
Se aplicaron técnicas de análisis exploratorio:

- Inspección inicial del dataset
- Tablas de contingencia (Nivel de obesidad vs Sexo)
- Gráficas de barras
- Comparación de promedios (Edad y Peso por sexo)

El análisis es de carácter descriptivo y no permite establecer relaciones causales.

## Principales resultados
- Se observan diferencias en la distribución de los niveles de obesidad entre hombres y mujeres.
- Los hombres presentan un peso promedio mayor.
- La edad promedio es similar entre ambos grupos.
- Algunos niveles de obesidad muestran mayor concentración en un sexo específico.

## Base de datos
El dataset incluye:

- Variables demográficas (Sexo, Edad)
- Variables físicas (Estatura, Peso)
- Variables de hábitos (Consumo de agua, vegetales, tabaquismo, etc.)
- Variable objetivo: **NivelDeObesidad**

Fuente: Universidad de la Costa (Colombia)
